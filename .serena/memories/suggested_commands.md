# Suggested commands

- Windows PowerShell blocks `npm.ps1` here; invoke scripts as `npm.cmd run <script>`.
- Development: `npm.cmd run dev`
- Production build/typecheck: `npm.cmd run build`
- Lint: `npm.cmd run lint`
- Preview a production build: `npm.cmd run preview`
- Project file search: `rg --files -g '!node_modules'` (can be slow in this repository).
